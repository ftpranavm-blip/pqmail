Known limitations (honest disclosure)

  • Educational prototype — not audited; do not use for real sensitive data.
  • Local key directory has no PKI: key authenticity relies on the local directory + fingerprints.
  • No forward secrecy across messages; a stolen unlocked session could read captured traffic for that identity.
  • Replay protection is per mailbox (ledger + age limit); a message can still be re-delivered to a mailbox that never received it.
  • The transparency log is local: it detects tampering with this directory but cannot prove other users see the same history.
  • Two-factor protects the web sign-in, not offline guessing of a stolen keystore file.
  • Python objects holding keys are not wiped from memory on GC (a Python runtime limitation).
  • QKD page is a simulation; it does not add real-world security.
